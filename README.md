# Gemini Agentic Video Analysis Example

This example demonstrates how to use Google's Gemini 1.5 Flash model to perform agentic video analysis. It uploads a local video file and prompts Gemini to not just summarize, but to identify critical events and suggest specific actions or follow-up questions, simulating an autonomous agent's decision-making process. This showcases Gemini's ability to understand video content deeply and respond contextually.

## Language

`python`

## How to Run

1. Set your `GOOGLE_API_KEY` environment variable.
2. Replace 'path/to/your/video.mp4' in `main.py` with the path to a local video file.
3. Run `python main.py`.
